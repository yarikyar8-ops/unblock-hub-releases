# Unblock Hub

**Один лаунчер для TG WS Proxy, Zapret и TikTok-прокси на Windows.**
Ставит, обновляет, запускает и сам подбирает рабочую стратегию — в одном окне.

## Скачать

➡️ **[Последняя версия (раздел Releases)](../../releases/latest)** — скачайте файл `UnblockHub-Setup-<версия>.exe` и запустите.

Системные требования: Windows 10 или 11, права администратора (нужны для драйвера WinDivert, на котором работает Zapret).

## Возможности

- Круглая кнопка питания для каждого приложения, таймер работы и выбранная стратегия.
- Автообновление с проверкой SHA256 и откатом на прошлую версию.
- Автокалибровка Zapret: подбирает рабочую стратегию под вашего провайдера.
- Пресеты сервисов и поиск адресов по названию, Game Filter для выбранных игр.
- TikTok: вставьте ссылку-подписку своего оператора, остальное программа сделает сама.
- Исправление hosts для Roblox, запуск вместе с Windows, значок в трее.
- Темы оформления, русский и английский языки, подсказки и питомец Хаби.

## Лицензия

Для работы нужен ключ. Получить его и **бесплатный пробный период (3 дня)** можно в Telegram-боте: **@unblockhub_keys_bot**.
Ключ вводится в программе: *Настройки → Лицензия → Ввести ключ*. Ключ привязывается к первому компьютеру, на котором его активировали.

## Если Windows или антивирус ругается

Установщик пока не подписан цифровым сертификатом, поэтому:

- **SmartScreen** («Windows защитила ваш компьютер»): нажмите «Подробнее» → «Выполнить в любом случае».
- **Антивирус** может реагировать на `winws.exe` и драйвер WinDivert: это стандартная реакция на инструменты обхода блокировок. Если файл удалён или заблокирован, добавьте папку программы в исключения и установите заново.

Проверить, что файл не подменён, можно по контрольной сумме SHA256, указанной в описании релиза:

```powershell
Get-FileHash .\UnblockHub-Setup-<версия>.exe -Algorithm SHA256
```

## Важно знать

- Результат зависит от вашего провайдера: универсального обхода не существует.
- Zapret и TG WS Proxy (автор Flowseal) и sing-box (SagerNet) — отдельные проекты со своими лицензиями; Unblock Hub — удобная оболочка для них.
- Для TikTok нужен сервер вашего оператора, он в программу не входит.
- Законодательство разных стран по обходу блокировок отличается; ответственность за использование лежит на пользователе.
